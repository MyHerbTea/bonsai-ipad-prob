# Bonsai RC1.20 — OpenAI API Quickstart

The iPad and client device must be on the same LAN. Keep Bonsai in the foreground.

1. Select the 27B GGUF in Bonsai.
2. Select the Q8 mmproj if vision requests will be used.
3. Start **局域网 OpenAI API**.
4. Tap **复制 API 配置**.

Use:
- Base URL: shown by the app, ending in `/v1`
- Model: `bonsai-2-27b-local`
- API key: generated by the app
- Authentication: `Authorization: Bearer <API key>`

Supported:
- `GET /v1/models`
- `GET /v1/models/bonsai-2-27b-local`
- `POST /v1/chat/completions`
- text requests
- vision requests with OpenAI-style `image_url` data URLs
- `stream=false`
- true chunked SSE with `stream=true`
- `stream_options.include_usage`
- `max_tokens` and `max_completion_tokens`

Current intentional limits:
- `n=1` only
- tools / tool_choice are not supported
- service is designed for one serialized local user/session rather than concurrent serving
